# library/textures — коллект исходников

Здесь лежат **копии** всех текстур (спрайтов и спрайт-атласов), которые
используют эффекты из `library/*.json`. Опись — `index.json` (id, имя в редакторе,
сетка листа `cols x rows @ fps`, в каком эффекте встречается).

Папка собирается командой из корня редактора:

```
node tools/collect.mjs            # обновить коллект
node tools/collect.mjs --prune    # плюс удалить осиротевшие файлы
```

Важно: **редактору эти файлы не нужны**. Каждый `library/*.json` самодостаточен —
пейлоад текстуры лежит внутри самого эффекта (ключ `tex`, data-URL), и при открытии
эффекта картинка восстанавливается оттуда. Коллект нужен, чтобы отдать исходники
вместе с проектом и чтобы с картинками можно было работать вне редактора.

Удаление файла отсюда ничего не ломает; правка файла здесь **не** меняет эффект —
чтобы обновить текстуру в эффекте, импортируйте её в панель Textures и сохраните эффект.
