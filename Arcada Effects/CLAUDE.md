# Arcaidia Effector — редактор 2D эффектов

Автономный редактор частиц (в духе Trapcode Particular) для сборки спрайт-атласов.
Ванильный JS + Canvas2D, ноль зависимостей. Папка самодостаточна и переносима:
все скиллы и документация лежат здесь же.

## ПРОТОКОЛ (ОБЯЗАТЕЛЬНО — до любой правки кода)

> ЗАПРЕЩЕНО редактировать файлы редактора без прочтения соответствующего SKILL.md.

1. Определить подсистему по таблице ниже
2. Прочитать нужный `skills/<skill>/SKILL.md` полностью
3. Следовать правилам и чеклистам скилла
4. Кросс-модульная задача — читать несколько скиллов последовательно

| Задача | Skill |
|---|---|
| **Создать/настроить ЭФФЕКТ как данные** (library/*.json, рецепты, проверка) | `skills/afx-effect-authoring/SKILL.md` |
| Симуляция, рендер, спрайты, треки/ключи, кривые, атлас, формат документа | `skills/afx-core-engine/SKILL.md` |
| Панели UI, виджеты, инспектор, таймлайн, график, превью, драги | `skills/afx-ui-panels-timeline/SKILL.md` |
| Рабочая сессия (workspace), каталог, сервер, локализация, тестирование | `skills/afx-workspace-catalog-i18n/SKILL.md` |

Справочники: `docs/ARCHITECTURE.md` (карта модулей, событийная шина, потоки данных),
`docs/FORMAT.md` (схема JSON эффекта, форматы треков, ключи localStorage).
Пользовательская документация: `README.md`.

## Запуск

- `run.bat` — поднимет `node server.mjs` (порт **5179**) и откроет браузер.
  С сервером каталог эффектов хранится в файлах `library/*.json`.
- Без сервера `index.html` тоже работает (каталог в localStorage).
- Автоматизация: deep-link `?open=<file.json>&t=<сек>&tab=preview|atlas&fresh=1`,
  синхронный рендер `AFX.Preview.renderNow(t)`, headless-проверка эффекта —
  `node tools/validate.mjs "library/<file>.json"` (детали — в скилле авторинга).
- Визуальная проверка без экрана: `await import('/tools/devsnap.js')` в консоли
  вкладки, дальше `AFXDev.sheet/frames/variants` — рендер уходит в `.snap/*.png`
  через `POST /api/snap`. Нужно, когда скриншот вкладки недоступен, и для
  покадрового сравнения итераций.
- Регрессия детерминизма: `node tools/simhash.mjs > before.txt`, правка ядра,
  снова `> after.txt`, `diff`. Хэш состояния симуляции ловит расхождение в
  последнем бите — «старые файлы попиксельно те же» проверяется этим, а не на глаз.
- Коллект исходников: `node tools/collect.mjs` выгружает текстуры всех эффектов в
  `library/textures/` + `index.json`. Перед передачей папки запускать его:
  ненулевой exit code = эффект ссылается на текстуру, пейлоада которой в файле нет.

## Базовые инварианты (ОБЯЗАТЕЛЬНО)

1. **Детерминизм** — симуляция строго воспроизводима: фиксированный шаг 1/120,
   сидированный RNG, никаких `Date.now()` / `Math.random()` в пути симуляции/рендера.
   Превью и экспортируемый атлас обязаны совпадать попиксельно.
2. **Зависимости** — не добавлять. Ни npm-пакетов, ни CDN. Classic scripts, без сборки.
3. **Совместимость файлов эффектов** — не ломать формат JSON. Новые поля добавлять
   с дефолтами в `Model.migrate()`; старые файлы обязаны открываться.
4. **i18n** — все новые видимые строки ТОЛЬКО на английском, через `L()`/`AFX.t()`,
   с записью перевода в RU-словарь `js/core/i18n.js`. Данные (имена слоёв, эффектов,
   пресетов) — английские, без обёртки.
5. **Undo-протокол** — `AFX.pushUndo()` ДО мутации (в драгах — по флагу первого move),
   `AFX.touch(layerId)` после, `AFX.commitEnd()` на завершении.
6. **Драги таймлайна** — любые pointer-драги внутри таймлайна оборачивать в
   `beginInteract()` / `endInteract()`, иначе ребилд DOM срывает драг.
7. **Код игры не трогать** — редактор ничего не импортирует из ARCADIA и наоборот;
   правки только внутри этой папки.

## Карта файлов

```
index.html          порядок загрузки скриптов (важен: utils -> i18n -> остальное)
css/editor.css      вся тема (тёмная, палитра ARCADIA)
js/core/            движок без DOM-зависимостей (кроме canvas):
  utils.js            события AFX.on/emit, math, rng, цвет, безье-изинг
  i18n.js             словарь EN->RU, AFX.t, AFX.setLang
  track.js            анимационные треки (ключи, изинги)
  curve.js            кривые за жизнь + градиенты (+пресеты)
  path.js             путь движения эмиттера (узлы-треки, запекание, ближайшая точка)
  sprites.js          процедурные спрайты, текстуры, кэши тонировки/свечения
  model.js            схема документа, фабрики слоёв, пресеты слоёв, миграции
  sim.js              детерминированная симуляция эмиттера
  engine.js           рендер композиции в момент t (изолированные инстансы)
  atlas.js            сборка спрайт-атласа (rgba / black / mask) + PNG-секвенция
  zip.js              минимальный ZIP (store) для экспорта секвенции
  fxpresets.js        заводские эффекты каталога
js/ui/              панели (DOM):
  dom.js              h(), SVG-иконки, контекст-меню, поповер, модалка, драг, сплиттеры
  widgets.js          виджеты инспектора (num/sel/curve/grad/sprite picker/bursts)
  ops.js              операции со слоями + выделение (sel/selLayers)
  textures.js         панель текстур (импорт, спрайт-атлас с диалогом сетки, drag в проект)
  inspector.js        инспектор выбранного слоя
  globalspanel.js     композиция, камера, экспорт атласа
  catalog.js          каталог эффектов (fs/localStorage, точки dirty)
  preview.js          центральное превью + вкладка атласа
  timeline.js         таймлайн: слои, ключи, кривые, графовый редактор
  app.js              состояние, undo, workspace, клавиатура, буфер слоёв, boot
server.mjs          статика + API библиотеки (library/*.json) + /api/snap, порт 5179
tools/validate.mjs  headless-валидатор файлов эффектов (Node, без DOM)
tools/collect.mjs   выгрузка текстур эффектов в library/textures (коллект исходников)
tools/simhash.mjs   хэш состояния симуляции: регрессия «старые файлы не поехали»
tools/devsnap.js    снимки рендера из вкладки в .snap/ (визуальная проверка без экрана)
library/            сохранённые эффекты пользователя (существующие не трогать;
                    новые эффекты добавлять НОВЫМИ файлами — см. скилл авторинга)
skills/             скиллы Claude (правила подсистем + авторинг эффектов)
docs/               архитектура и формат данных
```
