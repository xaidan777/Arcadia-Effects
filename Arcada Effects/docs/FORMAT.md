# Arcaidia Effector — форматы данных

## Файл эффекта (export/import, library/*.json)

```jsonc
{
  "app": "arcadia-effects",
  "v": 1,                       // версия схемы (Model.SCHEMA)
  "doc": { ...документ... },
  "tex": { "<texId>": "data:image/png;base64,..." },  // пейлоады текстур
  "thumb": "data:image/png;base64,..."                // миниатюра (пишет сервер)
}
```

## Документ (doc)

```jsonc
{
  "v": 1,
  "id": "fx_...",               // стабильный id (заводские: "factory:fx_...")
  "name": "Explosion — Top-Down",
  "comp": { "w": 512, "h": 512, "dur": 1.2, "fps": 60 },
  "cam":  { "comp": 37 },       // наклон камеры в градусах; scaleY = cos(comp)
  "exp":  {                     // настройки экспорта атласа
    "cols": 3, "rows": 3, "frames": 9,
    "cellW": 256, "cellH": 256,
    "t0": 0, "t1": -1,          // диапазон времени; t1 < 0 = до конца
    "mode": "rgba",             // rgba | black | mask
    "thr": 0,                   // порог маски (0 = мягкая)
    "ss": 2                     // суперсэмпл 1|2
  },
  "textures": [ { "id": "tex_...", "name": "smoke", "sheet": null } ],
  //            sheet: null | { "cols": 4, "rows": 4, "fps": 30 }  (футаж)
  "layers": [ ...слои, index 0 = ВЕРХНИЙ... ]
}
```

## Слой (общие поля)

```jsonc
{
  "id": "lr_...",
  "name": "Fire",
  "type": "emitter",            // emitter | sprite | atlas | postfx
  "on": true, "solo": false,
  "start": 0, "end": 1.2,       // окно слоя, сек; start МОЖЕТ быть < 0 (пре-ролл)
  "blend": "add",               // normal | add | screen | multiply
  "opacity": 1,                 // трек (см. ниже)
  "glowL": 0,                   // трек 0..3: послойное свечение (блюр слоя + аддитивно)
  "glowLR": 24,                 // радиус блюра послойного свечения, px
  "fadeOn": false,              // радиальное затухание слоя (маска destination-in)
  "fadeX": 0, "fadeY": 0,       // треки: центр затухания (гизмо в превью, драг двигает)
  "fadeR": 220,                 // трек: внешний радиус (ширина), px
  "fadeSoft": 0.5               // мягкая кромка как доля радиуса (0 — жёсткий срез)
}
```

Эмиттер: `start..end` — окно ЭМИССИИ (частицы доживают после end).
Спрайт: `start..end` — окно видимости.
Постэффект: `start..end` — окно, в котором он работает; `opacity` — СИЛА эффекта,
а `blend` / `glowL` / `fadeOn` для него мертвы (слой ничего своего не рисует).

## Трек (анимируемое значение)

Статика — просто число (для цвета — [r,g,b]). Анимация:

```jsonc
{ "keys": [
  { "t": 0,   "v": 0.3, "i": { "m": "ease" }, "o": { "m": "ease" } },
  { "t": 0.4, "v": 1.4, "i": { "m": "cust", "h": [0.62, 1] }, "o": { "m": "lin" } }
] }
```

- `t` — секунды ОТ НАЧАЛА СЛОЯ, `v` — число или [r,g,b].
- `i`/`o` — входной/выходной режим: `lin` | `ease` | `hold` (только o) |
  `cust` (h = [x, y] — контрольная точка сегмента, x в 0..1, y без ограничений).
- Изинг сегмента A->B = cubic-bezier из (A.o, B.i), см. Track.segControls.

## Слой-эмиттер: em + pt

```jsonc
"em": {
  "x": 0, "y": 0,               // треки; (0,0) = центр композиции, Y вниз
  "shape": "point",             // point | circle | ring | box | line
  "sx": 60, "sy": 60,           // размеры формы (кольцо: sx=радиус, sy=толщина)
  "dir": "out",                 // out | in | omni | dir
  "angle": -90, "spread": 40,   // треки, градусы
  "speed": 300,                 // трек, px/с
  "speedRnd": 0.5,
  "rate": 0,                    // трек, частиц/сек
  "subStep": true,              // рождение в свой момент шага и на позе эмиттера этого момента
                                //   v<2 -> false (вся пачка в начале шага, на позе начала шага)
  "bursts": [ { "t": 0, "n": 24 } ],  // t относительно начала слоя
  "path": {                     // ПУТЬ ДВИЖЕНИЯ: анимируемая ломаная/кривая эмиттера
    "on": false,                //   выкл — путь симуляции прежний, файл попиксельно тот же
    "mode": "emit",             //   emit — рождение вдоль пути | guide — ведение | both
    "closed": false,            //   замкнуть путь (от 3 узлов)
    "smooth": true,             //   Catmull-Rom через узлы (от 3 узлов); false — ломаная
    "nodes": [                  //   УЗЛЫ: смещения от (em.x, em.y); x/y — треки
      { "x": -140, "y": 0 },
      { "x": { "keys": [ { "t": 0, "v": -180 }, { "t": 0.3, "v": 180 } ] }, "y": -60 }
    ],
    "along": "random",          //   random | even (низкая дискрепанция) | start (в начале пути)
    "jitter": 0,                //   трек: разброс точки рождения поперёк пути, px
    "aim": "none",              //   none — работает em.dir | tangent — вдоль пути | normal — поперёк
    "attract": 0,               //   трек: пружина к ближайшей точке пути, 1/с^2
    "lock": 0,                  //   трек 0..1: прилипание к пути (1 — движение строго вдоль)
    "flow": 0,                  //   трек: скорость вдоль касательной, px/с (минус — назад)
    "fast": true                //   ведение: поиск ближайшей точки в окне вокруг прошлой
                                //   (дешевле в 3-5 раз; false — глобальный скан каждый шаг)
  },
  "branch": {                   // ветвление (молнии): дочерние частицы из позиции родителя
    "chance": 0,                // шанс ветки в секунду на частицу (0 = выкл)
    "spread": 35,               // отклонение угла ветки от направления родителя, град
    "lifeScale": 0.6,           // жизнь ветки как доля ОСТАТКА жизни родителя
    "sizeScale": 0.7,           // толщина/размер ветки как доля родителя
    "speedScale": 1,            // скорость ветки как доля скорости родителя
    "maxGen": 2                 // глубина поколений (ветки веток)
  },
  "sub": {                      // СУБ-ЭМИТТЕР: каждая частица слоя сама эмитит частицы
    "on": false,                // выкл — путь симуляции/рендера прежний, файл попиксельно тот же
    "emit": "death",            // life (по ходу жизни родителя) | death (при гибели) | both
    "rate": 20,                 // трек, частиц/сек НА КАЖДУЮ родительскую частицу (life/both)
    "count": 8,                 // выброс в момент гибели родителя (death/both)
    "startAt": 0,               // 0..1 — доля жизни родителя до начала эмиссии (life/both)
    "dir": "omni",              // omni | inherit (вдоль скорости родителя) | back | out (от центра эмиттера)
    "spread": 60,               // разброс угла для inherit/back/out, град
    "speed": 90,                // трек, px/с
    "speedRnd": 0.6,
    "inherit": 0.25,            // доля скорости родителя, добавляемая ребёнку
    "maxGen": 1,                // 1 — только дети; 2..4 — дети детей ТЕМ ЖЕ блоком sub.pt
    "genScale": 0.6,            // множитель size/life/rate на каждое следующее поколение
    "budget": 1500,             // кап живых дочерних частиц слоя (сверх — не рождаются)
    "under": false,             // рисовать детей ПОД родителями
    "pt": { /* полный блок частицы, схема ровно как у pt ниже */ }
  },
  "seed": 1
},
"pt": {
  "life": 0.8, "lifeRnd": 0.3,
  "render": "sprite",           // sprite | trail (линия пути частицы — молнии, следы)
  "trailCore": 0,               // 0..1 альфа белой линии-ядра поверх трейла
  "sprite": { "kind": "shape", "id": "smoke", "p": {} },
  //         | { "kind": "tex", "texId": "tex_..." }
  //         p: параметры фигуры (th, n, inr) + var (-1 = случайный вариант)
  "size": 90,                   // трек (значение при рождении)
  "sizeRnd": 0.4,
  "sizeOL":    { "pts": [ { "t": 0, "v": 0.25 }, ... ] },  // кривая за жизнь
  "sizeOT":    { "pts": [ ... ] },  // трейл: множитель ширины вдоль пути (0 — основание/спавн,
  \                                    1 — кончик/голова); константа 1 = прежний однородный штрих
  "opacityOL": { "pts": [ ... ] },
  "grad": { "stops": [ { "t": 0, "c": [255,248,224] }, ... ] },  // цвет за жизнь
  "tintTex": false,             // тонировать текстуру градиентом
  "rot": 0, "rotRnd": 1, "spin": 40, "spinRnd": 1,
  "alignVel": false, "stretch": 0,
  "gravX": 0, "gravY": 0,       // треки
  "drag": 2,
  "turbAmp": 0, "turbFreq": 1.5,  // turbAmp — трек; turbFreq — скорость «кипения» поля
  "turbMode": "noise",          // noise — независимый шум на частицу | curl — вихревое ПОЛЕ
  "turbScale": 90,              // curl: размер вихря, px (≈ ширина языка/завитка)
  "turbOct": 2,                 // curl: 1..4 октавы (крупная струя + мелкая рвань)
  "turbRise": 0,                // curl: px/с, поле всплывает вверх вместе с плюмом
  "turbWind": 0,                // curl: px/с, поле как СКОРОСТЬ среды (см. ниже)
  "turbSeed": 0,                // curl: вариация поля при том же дизайне
  "turbRamp": 0,                // 0..1: разгон амплитуды по жизни частицы (оба режима)
  "zigzag": 0,                  // град/с: покадровые случайные изломы направления (молния)
  "squash": 0,                  // 0..1 — насколько компрессия плющит сам спрайт
  "glow": 0,                    // 0..3 (выше 1 — доп. аддитивные проходы)
  "glowSize": 1.6, "glowBlur": 0.15,
  "fps": 0                      // для текстур-футажей; 0 = растянуть на жизнь
}
```

### Турбулентность: два режима

`turbMode: 'noise'` (дефолт, поведение файлов до появления curl) — у каждой частицы
СВОЙ шум по её собственному возрасту. Соседние частицы никак не связаны, поэтому
получается дрожание: детали много, структуры ноль.

`turbMode: 'curl'` — вихревое поле в МИРОВЫХ координатах, общее для всех частиц
слоя. Поле бездивергентно (`v = (dψ/dy, -dψ/dx)`): у потока нет источников и стоков,
частицы не «расталкиваются» и не «слипаются», а закручиваются. Соседние частицы
читают одну точку поля и уезжают ВМЕСТЕ связной струёй — отсюда языки и завитки.

`turbAmp` — сила как УСКОРЕНИЕ (px/с²). `turbWind` — то же поле как СКОРОСТЬ СРЕДЫ
(px/с): сопротивление считается относительно ветра, `v = W + (v + a·dt − W)·e^(−drag·dt)`.
Частицу несёт потоком, а не колотит им, поэтому она не перелетает вихрь и не
дребезжит. Ветер работает только при `drag > 0` — без сопротивления среда с
частицей не связана. `turbWind: 0` сворачивает формулу в прежнюю строку точно.

`turbRamp` (оба режима) гасит турбулентность у молодых частиц по smoothstep(0.04, 0.34)
доли жизни: у реального пламени основание ламинарное, а рвётся оно кверху.

## Слой-спрайт: sp

```jsonc
"sp": {
  "sprite": { "kind": "shape", "id": "soft", "p": {} },
  "size": 220,                  // базовый размер, px
  "x": 0, "y": 0,               // треки
  "scale": 1,                   // трек
  "aspect": 1,
  "rot": 0,                     // трек, градусы
  "color": [255,255,255],       // цветовой трек
  "squash": 0, "glow": 0,       // glow — трек 0..3
  "glowSize": 1.6, "glowBlur": 0.15,
  "fps": 0                      // футаж; 0 = растянуть на окно слоя
}
```

## Слой-атлас: type 'atlas'

Тот же блок `sp`, что у спрайта, и тот же путь рендера — отличий в схеме нет,
кроме `type`. Смысл отдельного типа: источник ВСЕГДА лист-текстура
(`sp.sprite.kind: 'tex'` у текстуры с `sheet`), а фабричные дефолты — СТАТИКА
(`opacity: 1`, `sp.scale: 1`, `blend: 'normal'`), без преданимации спрайта.
Кадр выбирается в engine: `sp.fps > 0` — по времени с зацикливанием,
`sp.fps = 0` — весь лист растянут ровно на окно слоя `start..end`.
Поля `sp.color` / `sp.glow` в этом типе не действуют (текстуры не тонируются),
в инспекторе и на таймлайне они не показываются.

## Слой постобработки: type 'postfx'

Слой-корректор (adjustment layer): своего изображения нет, он обрабатывает ПИКСЕЛИ
всего, что уже накоплено ПОД ним по стеку (слои с БОЛЬШИМ индексом в `doc.layers`).

```jsonc
"fx": {
  "effect": "mblur",            // mblur — смаз | displace — турбулентное искажение
  "mode": "directional",        // directional — смаз по углу | radial — зум + вращение от центра
  "length": 24,                 // трек: длина смаза, px (у radial — на дальнем углу кадра)
  "angle": 0,                   // трек: направление смаза, градусы (только directional)
  "spin": 0,                    // трек: угловой смаз вокруг центра, градусы (только radial)
  "x": 0, "y": 0,               // треки: центр радиального смаза (гизмо в превью)
  "samples": 16,                // 2|4|8|16|32|64 — сэмплов; набираются log2(N) проходами
  "half": false                 // считать смаз в буфере половинного размера
}
```

Дискриминатор вида эффекта — `fx.effect`, а НЕ `kind`: объект с полем `kind`
считается «атомом» в `Model.hydrate` и разреженный файл остался бы без дефолтов.

### effect: 'displace' — турбулентное искажение

Гнёт кадр под слоем полем турбулентного шума. ЯЗЫКИ ПЛАМЕНИ ДЕЛАЮТСЯ ИМЕННО ЭТИМ:
частицы дают мягкую светящуюся массу нужного силуэта, а форму — складки, рвань,
отрывающиеся лоскуты — режет искажение. Возить по полю фигурные спрайты вместо
этого бесполезно: выходит мозаика из одинаковых капель.

```jsonc
"fx": {
  "effect": "displace",
  "field": "swirl",             // swirl — бездивергентный вихрь | tear — свой шум по оси
  "amount": 26,                 // трек: размах смещения, px (opacity слоя его масштабирует)
  "scale": 60,                  // размер складки по горизонтали, px
  "aspect": 2.4,                // вытянутость складки по вертикали (огню нужно 2-3)
  "oct": 3,                     // 1..4 октавы
  "evo": 0.6,                   // Гц: скорость перерождения складок на месте
  "rise": 150,                  // px/с: поле уплывает вверх вместе с плюмом
  "ramp": 0,                    // 0..1: насколько гасить искажение НИЖЕ линии y0
  "y0": 0,                      // трек: линия успокоения, px (комп-координаты)
  "soft": 120,                  // на какой высоте ниже y0 гашение выходит на ramp
  "seed": 0
}
```

Отношения, которые решают всё (проверены перебором на пламени):

- `scale` ≈ ЧЕТВЕРТЬ ширины объекта. Складка шире объекта возит его целиком вбок —
  выходит покачивание, а не языки.
- `field: 'swirl'` сохраняет площадь и потому НЕ выбивает в массе чёрные дыры;
  `tear` рвёт резче, но дыры выбивает — на пламени они читаются как прогары.
  Зато `swirl` при КРУПНОЙ складке выгибает весь столб змейкой, а `tear` нет.
- `amount` ≈ 2·`scale` для swirl, ≈ 1·`scale` для tear.
- `ramp` обязателен всему, что стоит на земле: без него вихрь растаскивает
  раскалённое основание вбок и под столбом появляется яркая полоса-лужа.

Интерполяция поля на пиксели — СГЛАЖЕННАЯ (smoothstep), а не билинейная: у
билинейной рвётся производная на границах ячеек сетки, и при смещении в десятки
пикселей изломы вылезают в кадр сеткой складок-«горизонталей». Уже чинили.

Байпас (`opacity: 0`, либо `length: 0` при `spin: 0` / `amount: 0` у displace,
либо время вне окна слоя) не создаёт оффскрин композиции вовсе — кадр рисуется
прямо в целевой контекст.

## Мета атласа (кнопка Meta JSON)

```jsonc
{ "name": "...", "frameWidth": 256, "frameHeight": 256,
  "cols": 3, "rows": 3, "frames": 9, "fps": 8.18,
  "duration": 1.1, "compression": 37 }
```

Загрузка в Phaser: `this.load.spritesheet('fx', 'fx.png', { frameWidth, frameHeight })`.

## localStorage

| Ключ | Что |
|---|---|
| `afx.workspace` | рабочая сессия: `{cur: docId, entries: [{doc, dirty}]}` |
| `afx.tex.<id>` | dataURL текстуры |
| `afx.lang` | язык UI: `en` (дефолт) / `ru` |

| `afx.autosave` | legacy (одна копия), мигрируется и удаляется |

## Совместимость

Новые поля добавляются с дефолтами в `Model.migrate()` — любой старый JSON
обязан открываться. Ключи с префиксом `_` — runtime, в файлы не попадают.

## Разреженные файлы (авторинг инструментами)

`Model.hydrate()` (вызывается из `migrate`) дозаполняет недостающие поля
дефолтами фабрик `newDoc`/`newEmitter`/`newSprite`/`newAtlas`/`newPostFx`: файл может задавать только
отличия от дефолтов. Для полных документов гидрация — строгий no-op.
«Атомы» (трек `{keys}`, кривая `{pts}`, градиент `{stops}`, спрайт-реф `{kind}`)
не мержатся поключево — либо берутся целиком из файла, либо целиком из дефолта.
Проверка файла без браузера: `node tools/validate.mjs "library/<file>.json"`.
Выгрузка текстур в файлы (коллект для передачи проекта): `node tools/collect.mjs` —
пишет `library/textures/<имя>.<ext>` и опись `library/textures/index.json`
(id, имя, mime, размер, сетка листа, в каких эффектах встречается). Файлы эффектов
при этом НЕ меняются: пейлоад остаётся внутри JSON, выгрузка — копия.
Рабочий цикл и рецепты — `skills/afx-effect-authoring/SKILL.md`.
