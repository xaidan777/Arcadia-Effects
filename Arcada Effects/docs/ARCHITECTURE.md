# Arcaidia Effector — архитектура

Автономный редактор 2D эффектов на частицах. Ванильный JS (classic scripts,
без сборки и зависимостей), Canvas2D. Всё живёт в глобальном неймспейсе `window.AFX`.

## Слои системы

```
core (без DOM-зависимостей, кроме создания canvas)
  utils   события on/emit, math, mulberry32, цвет, bezierEase;
          детерминированный шум: noise1/noise2/noise3, turb3 (турбулентный fBm),
          curl2 / turbCurl3 (бездивергентные вихревые поля)
  i18n    AFX.t (EN ключ -> RU перевод), AFX.lang, AFX.setLang (reload)
  track   треки анимации: статика | {keys:[{t,v,i,o}]}, изинги сегментов
  curve   Curve (за жизнь частицы, 0..1) и Grad (градиент RGB) + пресеты
  path    Path: анимируемый путь эмиттера (запекание в полилинию, точка по длине дуги,
          ближайшая точка) — геометрия для эмиссии вдоль пути и ведения частиц
  sprites процедурные белые спрайты 128px, реестр текстур, кэши tint/glow
  model   схема документа, фабрики слоёв, layerPresets, migrate, (de)serialize
  sim     класс Sim: детерминированная симуляция одного эмиттера, DT=1/120
  engine  класс Engine: рендер документа в момент t (свои кэши Sim на инстанс);
          постэффекты слоя postfx: mblur (смаз draw-call'ами) и displace
          (турбулентное искажение по пикселям — им режутся языки пламени)
  atlas   сборка спрайт-атласа из футажа (кадры по центрам интервалов)
          + buildSequence: PNG-секвенция тем же сэмплингом (асинхронно, с отменой)
  zip     store-архиватор без зависимостей (секвенция уезжает одним .zip)
  fxpresets  заводские эффекты (строятся кодом через фабрики model)

ui (DOM, слушает события, мутирует doc через undo-протокол)
  dom       h(), иконки SVG, ctxMenu, popover, modal, drag-хелпер, сплиттеры
  widgets   виджеты инспектора; num-виджет умеет треки (секундомер+автокей)
  ops       операции со слоями, выделение (sel + selLayers)
  textures / inspector / globalspanel / catalog / preview / timeline  панели
  app       AFX.state, undo/redo, workspace-сессия, автосейв, клавиатура,
            буфер слоёв, boot
```

## Поток данных

```
мутация параметра (виджет/драг)
  -> AFX.pushUndo()            снапшот дока в undo-стек, dirty=true
  -> правка объекта doc         (объекты живые, без копий)
  -> AFX.touch(layerId)         layer._rev++  + emit('layer')
       -> timeline.queueRebuild (отложенно; подавлен во время драгов)
       -> preview.needsRedraw   рендер в rAF-цикле
       -> inspector updaters    обновление показанных значений
  -> AFX.commitEnd()            debounce-автосейв workspace в localStorage
```

Рендер кадра: `Engine.render(doc, t, ctx)` — для каждого слоя снизу вверх;
эмиттер: `Sim.ensure(layer, t - layer.start)` (ресим при откате/смене _rev),
отрисовка частиц с тонировкой из кэшей; спрайт-слой: eval треков и одна отрисовка.

## Ключевые решения

- **Детерминизм вместо кэшей**: перемотка назад = пересимуляция от нуля
  (сотни шагов — дёшево). Благодаря этому превью, миниатюры и атлас дают
  попиксельно одинаковый результат (у каждого свой Engine).
- **Время треков относительно начала слоя**: перенос бара двигает анимацию.
  Старт слоя может быть отрицательным (пре-ролл симуляции до нуля композиции).
- **Workspace-сессия**: переключение эффектов в каталоге не теряет правки —
  рабочие копии (с undo-историей) живут в Map по doc.id и переживают reload
  через localStorage. Сохранение в файл — только явной кнопкой.
- **Один формат файла**: эффект = JSON (док + dataURL текстур) — переносим
  импортом/экспортом, храним в library/ через мини-сервер (порт 5179) или
  в localStorage без сервера.
- **i18n словарём EN->RU**: исходники англоязычные, `AFX.t` переводит;
  смена языка перезагружает страницу (сессия не теряется).

## Жизненный цикл документа

```
boot: восстановление afx.workspace (все копии, кроме нетронутых пустых) -> applyDoc(текущая)
openDoc(doc): stashCurrent() -> workspace.get(doc.id) ? копия : свежий
saveCurrent: Catalog.saveCurrent (fs POST или localStorage) -> dirty=false
undo/redo: restore(json) -> замена state.doc -> ресинк ссылки в workspace
```

## Известные ограничения

- Живой смены языка нет (только через reload).
- Цветовые треки не редактируются в графовом редакторе (только в dope).
- Тонировка не работает для текстур-футажей (sheet) — рисуются как есть.
- rAF-цикл превью не тикает в скрытой вкладке браузерной панели (важно для
  тестов) — обход: синхронный `AFX.Preview.renderNow(t)`.

## Автоматизация (deep-link, headless)

- `?open=<file.json>&t=<сек>&tab=preview|atlas&fresh=1` — открыть эффект из
  library/ на старте (app.js: handleDeepLink; нужен сервер).
- `AFX.Preview.renderNow(t)` — синхронный рендер кадра (и пересборка атласа на
  вкладке atlas), возвращает `{tab, time, particles}`.
- `tools/validate.mjs` — поднимает js/core в Node (utils/track/curve/sprites/
  model/sim не требуют DOM при загрузке), валидирует файл эффекта и гоняет
  симуляцию. `Model.hydrate` дозаполняет разреженные документы дефолтами фабрик.
