# Arcaidia Effector

Автономный редактор 2D-эффектов на частицах в духе Trapcode Particular.
Цель — собирать спрайт-атласы эффектов (взрывы, дым, искры, волны) для игры.

Полностью standalone: ванильный JS + Canvas2D, ноль зависимостей, ноль npm install.
Код игры не трогает и ничего из него не импортирует. Папка самодостаточна и переносима.

Язык интерфейса: английский по умолчанию, русский — через шестерёнку справа
вверху (Settings -> Language; смена перезагружает страницу, сессия не теряется).
Имена пресетов и слоёв из пресетов — английские в обоих языках.

Кнопка «?» рядом с шестерёнкой — окно справки (о программе, версия, контакты автора).
Версия показана в топбаре рядом с логотипом; правится РУКАМИ в `index.html`
(`<meta name="afx-version" content="1.0.0">`), код читает её как `AFX.VERSION`.

Для Claude/LLM: протокол работы — [CLAUDE.md](CLAUDE.md), правила подсистем —
`skills/*/SKILL.md`, архитектура — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md),
форматы данных — [docs/FORMAT.md](docs/FORMAT.md).

## Запуск

1. Двойной клик по `run.bat` — поднимет сервер (`node server.mjs`, порт **5179**) и откроет браузер.
   С сервером эффекты сохраняются в файлы `library/*.json` (можно коммитить).
2. Либо просто открыть `index.html` в браузере — всё работает, но каталог хранится в localStorage.

Текущий эффект автосохраняется в localStorage и восстанавливается при перезапуске.

## Ключевые концепции

### Компрессия
Угол наклона камеры к плоскости эффекта: 0 = вид сбоку (круглый взрыв),
37 = изометрия игры (scaleY = 0.8, как `BASE_ISOMETRIC_COMPRESSION`).
Позиции частиц сплющиваются всегда; сплющивание самого спрайта — послойно
(параметр «Сжатие спрайта»: 1 для лежащих на земле колец, 0 для билбордов).

### Слои
- **Эмиттер (E)** — источник частиц: форма (точка/круг/кольцо/бокс/линия) или
  анимируемый **путь** (см. «Путь движения»), направление,
  скорость, поток и/или вспышки (bursts), жизнь, кривые размера/прозрачности за жизнь,
  градиент цвета за жизнь, гравитация, сопротивление, турбулентность, свечение, растяжение по скорости.
  Окно бара на таймлайне = окно ЭМИССИИ; частицы доживают после него.
- **Спрайт (S)** — одиночная графика: позиция, масштаб, поворот, цвет, свечение — всё анимируется ключами.
  Для вспышек, ударных волн, подсветок.
- **Post FX (F)** — слой постобработки: ничего своего не рисует, а обрабатывает
  готовый кадр всех слоёв НИЖЕ него (см. «Слой POST FX»).

Порядок строк на таймлайне: верхняя = рисуется поверх (перетаскивание за колонку имён).
Смешивание: normal / add / screen / multiply. Shift+клик — выделить несколько слоёв,
драг бара двигает всё выделение. **Старт слоя может быть отрицательным** (пре-ролл):
эффект в кадре с нулевой секунды, а симуляция началась раньше — зона до нуля подсвечена красным.

Свечение (в духе Deep Glow): «Свечение» — сила 0..3 (выше 1 — дополнительные аддитивные
проходы), «Размер свечения» — 0.2..4 диаметра, «Мягкость» — радиус блюра как доля размера спрайта.
Плюс **послойное свечение** (секция «Слой»: «Свечение слоя» 0..3, анимируется ключами,
и «Радиус свечения») — постобработка всего слоя блюром с аддитивным наложением;
основной способ заставить светиться молнии-трейлы и любые составные слои целиком.

### Контроллеры в превью (гизмо)
У выбранного слоя в превью рисуется крест-гизмо центра (эмиттера или спрайта) —
драг двигает позицию (с автокеем, если параметр анимирован). При включённом
«Радиальном затухании» появляется оранжевый круг-контроллер: драг его центра
двигает зону, «Затухание: радиус» (ширина, анимируется) и «Мягкость» — в
инспекторе; маска гасит слой по расстоянию от центра (для молний — затухание
всех веток; свечение слоя гаснет вместе с ними). У эмиттера с включённым путём
рисуется фиолетовая линия пути с квадратами-узлами: драг узла двигает его (с
автокеем), **дабл-клик по линии добавляет узел** между соседними, **дабл-клик по
узлу — удаляет** его (Alt+клик по линии тоже добавляет узел и сразу тащит его).
Дабл-клик мимо пути — как раньше, «вписать в окно».

**ПКМ в превью** открывает контекстное меню: на узле — анимировать узел (включает
треки X/Y), поставить ключ в текущем времени, снять анимацию, удалить узел;
на линии — вставить узел здесь; в любом месте при включённом пути — режим
(эмиссия / ведение / оба), сглаживание, замыкание, развернуть направление,
выключить путь; у эмиттера без пути — включить путь. Плюс общие пункты «Вписать»
и «Гизмо». Кнопка Gizmos в тулбаре скрывает контроллеры.

### Путь движения: анимируемая кривая как источник и направляющая
Секция «Путь движения» у эмиттера — это mask path в духе After Effects: набор
**узлов**, у каждого свои ключи X/Y, поэтому путь целиком анимируется. Узлы задаются
смещениями от позиции эмиттера, так что крест-гизмо двигает всю фигуру сразу.
Форма пути — ломаная или сглаженная кривая (Catmull-Rom, от 3 узлов), опционально
замкнутая.

Путь работает в трёх режимах («Режим пути»):

- **Эмиссия вдоль пути** — точка рождения частицы берётся с кривой (форма эмиттера
  в этом режиме не участвует). «Раскладка рождения»: случайно, равномерно вдоль пути
  или всегда в начале пути; «Разброс рождения» — сдвиг поперёк линии;
  «Направление вылета» — вдоль пути, поперёк или как задано в «Направлении» эмиттера.
  Два узла с ключами = **лазерный меч**: рукоять на месте, кончик проходит дугу
  замаха, частицы сыплются по всей длине клинка (пресет слоя «Blade (path)»).
- **Ведение частиц** — путь тянет уже родившиеся частицы: «Притяжение» (пружина
  к ближайшей точке пути, гасится «Сопротивлением»), «Прилипание к пути» (0..1;
  единица — частица движется строго вдоль линии и едет вместе с ней, когда путь
  анимирован), «Скорость потока» — движение вдоль касательной (минус — назад).
  S-кривая + прилипание + поток = частицы, бегущие по траектории (пресет слоя
  «Path Flow (S-curve)»). Галочка **«Быстрый поиск»** (включена по умолчанию) —
  оптимизация ведения: ближайшая точка пути ищется в окне вокруг найденной на
  прошлом шаге, а не глобальным сканом. На путях без самопересечений результат
  ПОБИТОВО тот же, а ресимуляция примерно втрое дешевле (это чувствуется при
  перемотке назад с большим числом частиц). Выключение возвращает строгий
  глобальный поиск — он нужен, если путь пересекает сам себя и частица должна
  перескакивать на другую ветвь. Флаг живёт в файле эффекта, а не в настройках
  редактора: от него зависит результат, а значит и экспортируемый атлас.
- **Эмиссия и ведение** — оба режима сразу.

Все параметры пути (включая X/Y каждого узла, разброс, притяжение, прилипание и поток)
анимируются ключами и видны на таймлайне отдельными строками; ведение действует на
частицы самого слоя — дочерние частицы суб-эмиттера летят свободно.

### Молнии: трейлы, ветвление, зигзаг
У эмиттера есть рендер «Трейл» — частица рисуется линией своего пути (со свечением
и белым ядром), «Зигзаг» — покадровые изломы направления, и секция «Ветвление»:
частица в полёте с заданным шансом порождает ответвление из своей позиции (угол
± разброс, короче и тоньше родителя, до N поколений), основная летит дальше и
затухает по своим кривым. Пресет слоя «Lightning» и заводской эффект
«Lightning Strike» (небо-вспышка, разряд, удар в землю с искрами) — готовые примеры.

### Суб-эмиттер: частица как эмиттер
Секция «Суб-эмиттер» превращает каждую частицу слоя в самостоятельный эмиттер —
многоуровневая система в духе Aux System из Trapcode Particular. У дочерней частицы
**свой полный блок настроек** (спрайт, жизнь, кривые размера и прозрачности,
градиент, физика, свечение, режим трейла) — это и отличает суб-эмиттер от
«Ветвления», где ребёнок наследует внешность родителя.

- **Эмиссия**: «при гибели родителя» (выброс N частиц — вторичный взрыв, фейерверк),
  «по ходу жизни» (темп в секунду на каждую родительскую частицу — шлейф, дым за искрой)
  или оба режима сразу.
- **Направление**: во все стороны, вдоль скорости родителя, против неё или от центра
  эмиттера; плюс наследование доли скорости родителя.
- **Макс. суб-поколений** больше 1 — дети сами эмитят детей тем же блоком настроек,
  каждое следующее поколение мельче и короче на «Масштаб поколения».
- **Суб-бюджет** — жёсткий кап живых дочерних частиц. Темп умножается на число живых
  родителей, поэтому счётчик частиц взлетает быстро: 20/с при 200 родителях — это
  4000 частиц в секунду. Начинайте с режима «при гибели», он самый дешёвый.

Пресет слоя «Firework (sub-emitter)» — готовый пример.

### Работа с несколькими эффектами
Переключение в каталоге не сбрасывает правки: у каждого эффекта своя рабочая копия
в сессии (с собственной историей Ctrl+Z), несохранённые помечены точкой, кнопка
«Сохранить» подсвечена. Рабочая сессия переживает перезагрузку страницы (localStorage).
ПКМ по строке каталога — «Сбросить правки» (вернуться к сохранённой/заводской версии).
Перенос слоёв между эффектами: выделить слои (Shift+клик) — **Ctrl+C**, переключиться
на другой эффект — **Ctrl+V**: слой переносится целиком, вместе с метой нужных текстур.

### Спрайты частиц
Пресеты: мягкий круг, круг, кольцо, квадрат, полигон, звезда, штрих, искра,
клуб дыма, мульт-клуб, осколок (у последних 4 варианта формы — фиксированный или случайный).
Плюс любые импортированные текстуры; текстуру можно пометить кнопкой «Сетка» как футаж
(cols/rows/fps) — частицы и спрайт-слои проигрывают её по кадрам.

### Слой ATLAS (кнопка «+ Atlas» на таймлайне)
Отдельный тип слоя: настройки как у спрайта (позиция, размер кадра, scale, поворот,
blend, непрозрачность, послойное свечение, радиальное затухание), но источник — только
лист-текстура, и НИКАКОЙ фабричной преданимации (у «+ Sprite» дефолт — анимированные
scale и opacity, для атласа это мусор).

- Кнопка ВСЕГДА открывает диалог «Спрайт-атлас»: сверху зона броска и «Выбрать файл...»,
  ниже — листы, уже загруженные в проект (клик по миниатюре), дальше превью с сеткой,
  чипы кратных сеток и поля столбцов/строк/fps. «Принять» добавляет лист в проект
  (если он новый) и создаёт слой, «Отмена» не делает ничего.
- Бар слоя выставляется в натуральную длительность листа (кадры / fps), а `Footage FPS = 0`
  растягивает кадры ровно на бар: тянешь край бара — меняешь скорость проигрывания.
  Поставь FPS > 0, если нужен циклический проигрыш с фиксированной скоростью.
- Кнопки инспектора: «Import sheet...» (импорт нового листа прямо в слой) и «Сетка»
  (правка cols/rows/fps текстуры в том же диалоге с превью).
- Перетаскивание текстуры-листа из панели текстур в превью/на таймлайн тоже создаёт ATLAS-слой.

### Слой POST FX (кнопка «+ Post FX» на таймлайне)
Слой-корректор в духе adjustment layer After Effects: своей картинки у него нет,
он берёт всё, что уже нарисовано СЛОЯМИ НИЖЕ него на таймлайне, и обрабатывает
пиксели. Пока в нём один эффект — **смаз движения (motion blur)**.

- **Режимы.** «По направлению» — один угол смаза на весь кадр (рывок камеры,
  проезд, whip pan). «Радиальный» — зум и/или вращение вокруг центра (удар,
  взрыв, попадание); центр двигается крестом-гизмо прямо в превью.
- **Длина** — в пикселях, анимируется ключами (у радиального это смаз на дальнем
  углу кадра, ближе к центру он естественно меньше). Длина 0 = слой ничего не делает.
- **Сила эффекта** — это `opacity` слоя: подмешивание обработанного кадра к чистому.
  0 — полный байпас, 1 — только размытый кадр. Тоже анимируется.
- **Окно бара** — время, когда постэффект работает; вне бара кадр идёт нетронутым.
- **Качество.** «Сэмплы» 2..64 набираются проходами-удвоениями: 16 сэмплов стоят
  4 прохода по кадру, а не 16 отрисовок. Мало сэмплов на длинном смазе = видимые
  ступеньки-призраки; поднимай сэмплы. «Половинное разрешение» считает смаз в
  вчетверо меньшем буфере — быстрее и чуть мягче.
- Качество — свойство ЭФФЕКТА, а не превью: экспортируемый атлас получается
  ровно таким же, каким выглядит превью.
- **Ставь слой как можно ниже в стеке.** Сам смаз считает GPU и он почти
  бесплатен, а вот слои ПОД постэффектом рисуются в побочную канву — это дороже
  примерно в полтора раза за отрисовку. Всё, что выше постэффекта, идёт напрямую
  и ничего не стоит. На 2000 частиц разница между «постэффект сверху» и
  «постэффект над последними 500 частицами» — 6.2 мс против 0.9 мс на кадр.
- Смаз идёт по пикселям готового кадра, поэтому направление у него ОДНО на кадр.
  Если нужно, чтобы КАЖДАЯ частица смазывалась по своей скорости, это не сюда —
  это «Растяжение по скорости» в блоке частицы эмиттера.

### Спрайт-атлас (импорт готового листа)
Кнопка **«Атлас»** в панели текстур открывает тот же диалог, но только импортирует лист
(слой не создаётся). Сетка предлагается автоматически:
сетка предлагается по соотношению сторон листа (квадратные ячейки), поверх превью
рисуются линии, рядом — чипы других кратных сеток (2×1, 4×2, 8×4 …) и поля
столбцов/строк/fps. «Принять» кладёт текстуру в проект уже размеченной как футаж,
«Отмена» не добавляет ничего. Диалог сетки открывает и кнопка «Сетка» у обычной
текстуры, когда футаж включается.

### Анимация и ключи
- Секундомер у параметра включает трек; правка значения при включённом треке ставит ключ
  в текущем времени (автокей). Ромб — поставить/убрать ключ вручную.
- Время ключей хранится ОТ НАЧАЛА СЛОЯ: перенос бара двигает всю анимацию слоя.
- ПКМ по ключу: Линейный / Плавный (Easy Ease) / Плавный вход / Плавный выход / Ступенька (Hold).
- Кнопка графика в таймлайне — графовый редактор: драг ключей по времени и значению,
  у выбранного ключа появляются безье-ручки (кастомный изинг), дабл-клик — добавить/удалить ключ.
- Кривые «за жизнь частицы» (размер/прозрачность) редактируются в двух местах: мини-редакторы
  в инспекторе и большой график в таймлайне (клик по строке кривой у раскрытого эмиттера;
  ось X — жизнь 0..1). Градиент цвета за жизнь — тоже прямо на таймлайне: клик по полосе
  добавляет стоп, драг двигает, ПКМ удаляет, дабл-клик — выбор цвета.

### Экспорт атласа
Сетка (колонки х ряды), число кадров, размер ячейки, диапазон времени, сглаживание 2x.
Кадры сэмплируются по центрам интервалов, так что первая ячейка не пустая.
Режимы:
- **Цвет, прозрачный фон** — обычный RGBA-атлас;
- **Цвет на чёрном** — как второй референс (взрыв сбоку);
- **Маска (белое на чёрном)** — как референс дымовой маски; «Порог» бинаризует края.

«Мета JSON» — frameWidth/frameHeight/frames/fps в буфер обмена. Кнопки вывода живут
в верхней панели (за разделителем после «Сохранить»): **Скачать PNG** — файл атласа
по текущим настройкам экспорта.

### Экспорт секвенции
**Экспорт секвенции** в верхней панели открывает диалог: размер кадра, fps, диапазон
времени, режим (те же три, что у атласа), сглаживание 2x и имя файла. На выходе один
**.zip** с нумерованными кадрами (`Имя_0000.png`) и `meta.json`. Кадры сэмплируются
так же, как ячейки атласа, поэтому при равных настройках кадр N секвенции попиксельно
равен ячейке N атласа. Потолок — 600 кадров; настройки секвенции живут в сессии
и в эффект НЕ записываются.
Загрузка в Phaser: `this.load.spritesheet('fx', 'fx.png', { frameWidth: W, frameHeight: H })`.

## Детерминизм

Симуляция частиц идёт фиксированным шагом (1/120 с) от нуля с сидированным RNG,
поэтому перемотка в любую точку, превью и экспорт дают попиксельно одинаковый результат.
Seed эмиттера меняется в инспекторе — другой вариант рассыпки при тех же параметрах.

## Структура

```
index.html          точка входа (classic scripts, без сборки)
css/editor.css      тема в палитре проекта
js/core/            движок: utils, track (ключи/изинги), curve (кривые/градиенты),
                    path (путь движения эмиттера),
                    sprites (процедурные спрайты, тонировка), model (документ),
                    sim (симуляция), engine (рендер), atlas (сборка атласа),
                    fxpresets (заводские эффекты)
js/ui/              панели: dom, widgets, ops (операции со слоями), textures,
                    inspector, globalspanel, catalog, preview, timeline, app
server.mjs          статика + API библиотеки (library/*.json), без зависимостей
library/            сохранённые эффекты (JSON с текстурами внутри)
library/textures/   коллект: те же текстуры отдельными файлами + index.json
tools/              validate.mjs (проверка эффекта), collect.mjs (сбор текстур)
```

Формат эффекта — один JSON: документ + dataURL текстур, переносится импортом/экспортом.

## Передача проекта (коллект)

Папка редактора самодостаточна: каждый `library/*.json` хранит свои текстуры
внутри себя (data-URL в ключе `tex`), абсолютных путей и внешних зависимостей нет —
папку можно копировать целиком на другую машину и запускать.

Перед передачей:

1. Сохранить черновики (группа **Unsaved** в каталоге, оранжевые точки — несохранённое):
   рабочая сессия живёт в localStorage браузера и вместе с папкой НЕ переезжает.
2. `node tools/collect.mjs` — обновить `library/textures/` и убедиться, что ошибок нет
   (ошибка = эффект ссылается на текстуру, которой в файле нет).
3. `node tools/validate.mjs` — все эффекты открываются и считаются.

На новой машине нужен только Node (для `run.bat`); без него работает и `index.html`,
но каталог тогда живёт в localStorage, а не в `library/`.
