# AFX: сессия, каталог, локализация, тесты

## Рабочая сессия (workspace, app.js)

- `workspace: Map(docId -> {doc, dirty, ts, undo, redo, time, sel})` — рабочие копии
  ВСЕХ открывавшихся эффектов. Переключение каталога НЕ теряет правки:
  `AFX.openDoc(doc)` стешит текущий; `{fresh:true}` — выбросить копию и открыть заново.
- ПРАВИЛО ПОБЕДИТЕЛЯ в openDoc: ГРЯЗНАЯ копия побеждает переданный док
  (несохранённые правки — фича), ЧИСТАЯ — УСТУПАЕТ свежезагруженному контенту
  (файл/заводской пресет авторитетнее; иначе после Save клик по каталогу
  показывает устаревшую копию — реальный баг «молнии после загрузки иначе»).
  time/sel/undo чистой копии переносятся в новую.
  Правило действует И когда этот же эффект УЖЕ ОТКРЫТ (совпадают id): чистый
  док перечитывается из файла, грязный остаётся. Раньше был ранний return — и
  устаревшая копия сессии висела на экране навсегда: клик по строке каталога
  не перечитывал файл. Свой же объект (`state.doc === doc`, клик по черновику) — no-op.
- МУЛЬТИВКЛАДОЧНОСТЬ: `saveWorkspaceLS` НЕ затирает весь `afx.workspace`, а
  мержит записи по doc.id с меткой `ts` (последняя правка, `state.docTs`,
  бампится в pushUndo) — запись другой вкладки с более свежим ts выживает.
  Кап: грязные все + новейшие чистые до WS_MAX.
- `entry.doc` — ЖИВАЯ ссылка на объект. После `restore()` (undo/redo) объект
  заменяется — обязательно пересинхронизировать `ws.doc = doc` (уже сделано,
  не сломай).
- LRU-вытеснение: только ЧИСТЫЕ записи (dirty никогда не вытесняется).
- Автосейв: debounce 700мс -> `saveWorkspaceLS()` пишет `afx.workspace`
  (все копии) + пейлоады текстур `afx.tex.<id>`. `AFX.flushAutosave()` —
  немедленный сброс (звать перед reload, напр. при смене языка).
- КВОТА localStorage: запись сессии НЕ имеет права падать МОЛЧА — застывшая
  копия с dirty=true перебивает только что сохранённый файл при следующем
  открытии (именно так «терялись» настройки после Save). Порядок: чистим
  осиротевшие `afx.tex.<id>` (нет ни в одной записи) -> пишем -> не влезло:
  только грязные -> всё равно не влезло: `removeItem('afx.workspace')` +
  статус-строка (файлы авторитетнее протухшей сессии; следующий автосейв
  запишет сессию заново из памяти).
- Идентичность: заводские пресеты получают стабильный id `factory:<id>` в
  catalog.js. Переименованные сейвы ДЕЛЯТ doc.id (несколько файлов = один
  док) — это осознанно, не "чинить".
- dirty: ставится в `pushUndo`, снимается в `AFX.saveCurrent` и `loadDoc/openDoc`
  чистой копии; каталог рисует оранжевые точки по `AFX.wsDirty(id)`.
- SAVE: `Catalog.saveCurrent(done)` сообщает ФАКТ записи (fs-режим асинхронный).
  Только по `ok` снимается dirty И СРАЗУ зовётся `AFX.flushAutosave()`: иначе в
  `afx.workspace` остаётся копия dirty=true с содержимым ДО сохранения, и после
  перезагрузки она побеждает файл (выглядит как «Save не сохранил»). Ошибка
  сервера/квоты ОБЯЗАНА оставить эффект грязным.
- Черновики: рабочие копии БЕЗ строки в каталоге (новые "New", импорт с чужим id)
  показываются в группе Unsaved через `AFX.wsList()` (текущий док + workspace,
  фильтр по известным id user+factory). Клик = `AFX.openDoc(AFX.wsGetDoc(id))`,
  "Remove from session" = `AFX.wsDelete`. После Save черновик уезжает в Mine
  (id совпадает). Не ломать: без этой группы новый эффект теряется при переключении.
- НЕТРОНУТЫЙ пустой док (`pristineDoc`: не dirty, ни слоёв, ни текстур — свежий
  "New Effect") НЕ стешится, НЕ пишется в localStorage и НЕ восстанавливается
  на старте: иначе несохранённый "New Effect" воскресал при каждом запуске.
  Правка/undo-история делает док обычным черновиком.
- `wsDelete` копит удалённые id (`wsDeleted`): merge в `saveWorkspaceLS` обязан
  пропускать их при чтении stored — иначе удалённая из сессии копия воскресает
  из localStorage при следующем автосейве.
- Буфер слоёв: `AFX.copyLayers/pasteLayers` (Ctrl+C/V) — клоны с новыми id +
  перенос меты текстур в целевой док (пейлоады в глобальном реестре).

## Каталог и сервер

- Два режима: fs (сервер отвечает на `api/list`) и localStorage-фолбэк.
  Определяется на старте (`detectServer`), UI обязан работать в обоих.
- Сервер (server.mjs, порт **5179**, ноль зависимостей): `api/list`
  (file,name,id,thumb), `api/effect?f=`, `api/save`, `api/delete`. Пишет только
  в `library/`, имена через safeName. После правок server.mjs — ПЕРЕЗАПУСТИТЬ
  процесс node.
- Удаление эффекта из каталога зовёт `AFX.wsDelete(id)` — чистит скрытую
  рабочую копию (иначе утечёт в localStorage навсегда).
- `library/*.json` руками не редактировать — это данные пользователя.
- КОЛЛЕКТ (`node tools/collect.mjs`): выгружает пейлоады текстур из `library/*.json`
  в `library/textures/<имя>.<ext>` + `index.json` (идемпотентен, `--prune` чистит осиротевшие).
  Это КОПИЯ для передачи проекта: редактор читает текстуры ИЗ ФАЙЛА ЭФФЕКТА, не из этой папки —
  не заводить загрузку по пути и не вырезать `tex` из JSON (сломает импорт/экспорт одним файлом).
  Запускать после добавления эффектов с текстурами и перед передачей папки.

## Локализация (i18n.js) — ЖЁСТКИЕ ПРАВИЛА

- Исходные строки в коде — ТОЛЬКО английские. Показ через `L('English text')`
  (локальный алиас `const L = AFX.t;` в шапке модуля).
- Каждый новый ключ ОБЯЗАН получить перевод в RU-словаре `js/core/i18n.js`
  (ключ = точная английская строка; нет в словаре — молча покажется английский).
- ДАННЫЕ не переводятся и не оборачиваются: имена слоёв/эффектов, `doc.name`,
  имена заводских пресетов (по требованию — английские всегда), суффикс ' copy'.
  ЛЕЙБЛЫ меню/дропдаунов пресетов — переводятся в точке показа: `L(p.label)`.
- Язык: `localStorage 'afx.lang'`, дефолт **en**. Смена — `AFX.setLang(l)`:
  flushAutosave + `location.reload()` (живой перевод без перезагрузки НЕ
  поддерживается — не пытаться).
- `i18n.js` грузится сразу после `utils.js` (порядок в index.html) — до всех
  потребителей.
- Проверка полноты: скан кириллицы в строковых литералах вне i18n.js
  (регэксп `'[^']*[А-яЁё][^']*'`) должен давать пусто (исключение — 'Русский'
  в селекторе языка).

## Рецепт тестирования (браузерная панель)

1. Поднять сервер фоново: `node server.mjs` из папки редактора; открыть вкладку
   на `http://localhost:5179/`.
2. Проверки — через javascript-eval и чтение консоли (ошибки = провал).
3. **rAF в скрытой вкладке НЕ тикает**: плейбек и всё на requestAnimationFrame
   не проверить кодом — тесты писать синхронно (явные `TL.rebuild()`,
   `Engine.render`, `AFX.Preview.renderNow(t)`), плейбек оставлять на глаза
   пользователя. Загрузка эффекта из library на старте — deep-link
   `?open=<file.json>&t=<сек>&tab=preview|atlas&fresh=1`.
4. Драги симулировать PointerEvent'ами (pointerdown на элементе, pointermove/up
   на window); `TL._dbg()` отдаёт pps/timeMin/interacting.
5. **НЕ МУТИРОВАТЬ данные пользователя**: его рабочие копии (workspace),
   `library/*.json` и localStorage — чужое. Тестовые правки делать на СВОЁМ
   доке (`AFX.Model.newDoc()`), после теста убирать копию из сессии и
   откатывать undo. Был инцидент с загрязнением пользовательского эффекта.
6. Детерминизм проверять двумя независимыми Engine на одном t (пиксели равны).
