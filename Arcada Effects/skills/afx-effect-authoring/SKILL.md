# AFX Авторинг эффектов

Этот скилл — про сочинение эффектов (JSON в `library/`), а не про правку кода
редактора. Для кода — три других скилла (см. CLAUDE.md).

Главная опасность авторинга — НЕ ошибка в числах, а **узкий инструментарий**:
собрать всё из «эмиттер + вспышка + искры», потому что этот приём вспоминается
первым. Движок умеет много больше. Прежде чем писать первый слой — пройти
«Карту возможностей» и осознанно выбрать механизмы.

## Права на запись (ЖЁСТКО)

- Новый эффект = НОВЫЙ файл `library/<Name>.json`. СУЩЕСТВУЮЩИЕ файлы пользователя
  не перезаписывать и не «улучшать» без его явной просьбы.
- Имя файла = имя эффекта после `safeName` (символы `\/:*?"<>|` → `_`, ≤80 зн.).
- **doc.id и id всех слоёв задавать явно и стабильно** (`fx_<slug>`, `lr_<slug>_1` …).
  Без id гидрация сгенерит случайные — каждый reload создаст «новый» документ,
  и рабочие копии в сессии начнут плодиться.
- При итерациях НЕ менять doc.id/имя файла — чистая копия сессии уступает файлу,
  и редактор подхватывает каждую перезапись.
- Данные — английские: имя эффекта, имена слоёв (в старых файлах пользователя
  бывает русский — это его данные, не трогать).

## Рабочий цикл

```
1. Пройти КАРТУ ВОЗМОЖНОСТЕЙ (ниже) — выбрать механизмы под задачу
2. Прочитать эталон, ближайший к задаче (см. Рецепты) — library/*.json
3. Написать library/<Name>.json (разреженно, см. Формат)
4. node tools/validate.mjs "library/<Name>.json"
     структура, опечатки ключей, enum'ы, треки/кривые, сим-прогон (peak частиц)
5. Открыть в браузерной панели:
     http://localhost:5179/?open=<Name>.json&tab=atlas        вся анимация одним экраном
     http://localhost:5179/?open=<Name>.json&t=0.3            стоп-кадр превью
     &fresh=1 — выбросить рабочую копию (грязная копия иначе побеждает файл)
6. Смотреть результат:
     деп-линк грузит эффект АСИНХРОННО — перед проверками дождаться
       `AFX.state.doc.id === '<мой id>'` (поллинг), иначе гонка с boot-доком;
     видимая вкладка -> скриншот;
     скрытая вкладка (rAF не тикает) -> javascript-eval:
       AFX.Preview.renderNow(0.3)   // {tab, time, particles}, рендер синхронно
     пиксельная проверка без экрана: new AFX.Engine().render(doc, t, ctx) в
       оффскрин-canvas + getImageData (см. тест-рецепт workspace-скилла);
     параллельные сессии Claude делят вкладки панели — работать в СВОЕЙ
       вкладке (tabs_create) и адресовать её по tabId
7. Править файл -> reload той же ссылки -> повторять до результата
```

Деп-линк требует сервера (`node server.mjs`, порт 5179). Детерминизм гарантирует:
один и тот же JSON — попиксельно тот же результат, скриншоты сравнимы между итерациями.

## КАРТА ВОЗМОЖНОСТЕЙ

Полный список того, чем движок умеет делать форму и движение. Колонка «эталон» —
где приём УЖЕ собран и его можно прочитать; «—» значит, что в library его никто
не применял: приём рабочий, но примера нет, детали брать из `docs/FORMAT.md`.

| Механизм | Ключи | Что даёт | Эталон |
|---|---|---|---|
| Форма источника | `em.shape` point/circle/ring/box/line + `sx/sy` | откуда рождаются частицы | Shockwave (ring), Flame Pro (box); `line` — нигде |
| Направление | `em.dir` out/in/omni/dir + `angle/spread` | куда летят | Explosion (out, omni), Poison (dir); `in` — нигде |
| Залп vs поток | `em.bursts[]` / `em.rate` | удар vs луп | Sparks (burst), flame (rate) |
| Ритм залпов | несколько записей в `bursts` | эхо, двойной удар, очередь | — |
| **Анимация эмиттера** | треки на `em.x y sx sy angle spread speed rate` | движущийся/разворачивающийся источник | только `rate` в Flame Pro |
| **Путь движения** | `em.path` (emit/guide/both) | луч, дуга клинка, орбита, ведение по кривой | railgun, saber |
| **Суб-эмиттеры** | `em.sub` | частица сама сыплет частицы: шлейф, распад, вторичка | flame, Poison |
| Ветвление | `em.branch` | молнии, трещины, разряды | Explosion, factory `fx_lightning` |
| Трейлы | `pt.render:'trail'` + `sizeOT` + `trailCore` | линия пути вместо спрайта | Poison, saber, Explosion |
| Curl-турбулентность | `pt.turbMode:'curl'` + `turbScale/Wind/Rise/Ramp` | связные струи, языки, завитки | Flame Pro |
| Шумовая турбулентность | `turbMode:'noise'` + `turbAmp/turbFreq` | дрожание на частицу (снег, споры) | flame, Poison, saber |
| Излом | `pt.zigzag` | покадровые рывки (молния, глитч) | Explosion, Flame Pro |
| **Постэффект: смаз** | `type:'postfx'`, `fx.effect:'mblur'` | скорость, вращение, шаттер | railgun (directional), saber (radial) |
| Постэффект: искажение | `fx.effect:'displace'` | языки, рвань, портал, марево | Flame Pro |
| **Силовое поле** | `type:'force'`, `ff.fields[]` | воронка, отброс, вихрь — сила ВНУТРИ симуляции | Flame Pro |
| **Адресация корректора** | `targets:[id...]` у `postfx` / `force` | эффект только на выбранные слои, а не на всё ниже | — |
| Слой-спрайт | `type:'sprite'` | вспышка, кольцо, подложка, готовая картинка | все |
| **Слой-футаж** | `type:'atlas'` + текстура со `sheet` | пре-рендеренная секвенция в композиции | Capacitor, Poison |
| Текстуры | `sprite:{kind:'tex'}`, `tintTex` | свои картинки как частицы | Explosion (tintTex), Capacitor |
| Свечение слоя | `glowL` + `glowLR` | ореол по всему слою (единственный способ для трейлов) | railgun, saber, Explosion |
| Радиальное затухание | `fadeOn` + `fadeX/Y/R/Soft` | обрезать у земли, локализовать свет | Explosion, railgun |
| Камера | `cam.comp` | изометрия (сплющивание по Y) | Explosion, Poison, Shockwave |
| **Размер композиции** | `comp.w/h` | кадр под задачу, а не всегда 512×512 | railgun (512×32), Poison (128×128) |
| Режим экспорта | `exp.mode` rgba/black/mask + `thr` | маски и аддитивные листы | factory `Smoke — Mask` |
| Окно атласа | `exp.t0/t1` | обрезка и вырезание периода лупа | Capacitor, flame |
| Blend | `add` / `screen` / `normal` / `multiply` | — | screen: Flame Pro, flame, saber; multiply — нигде |

### Правило охвата

Перед сборкой пройти карту сверху вниз и выбрать механизмы ОСОЗНАННО. Ориентир:

- **Масштабы.** Живой эффект держит минимум три: крупный (масса/вспышка),
  средний (основное движение), мелкий (искры/крошка/детали). Один масштаб = плакат.
- **Хотя бы один структурный механизм** из выделенных жирным: путь, суб-эмиттер,
  анимация эмиттера, постэффект, футаж. Без них получается «шарики разлетелись
  из точки» — ровно то, что пишется по умолчанию.
- **Сколько строк карты реально задействовано.** 3–4 — почти наверняка плоско.
  8–12 — нормальный боевой эффект (эталонный Explosion: 7 слоёв, 12 механизмов).
- Если приём помечен «—», это не значит «не работает»: значит, примера в library
  нет, параметры брать из `docs/FORMAT.md`, а результат смотреть глазами.

## Формат: разреженный JSON

`Model.hydrate` (внутри `migrate`) дозаполняет ВСЕ отсутствующие поля фабричными
дефолтами. Пишем только отличия:

```jsonc
{ "app": "arcadia-effects", "v": 1,
  "doc": {
    "id": "fx_my_burst", "name": "My Burst",
    "comp": { "dur": 0.9 },                    // w/h/fps дозаполнятся (512/512/60)
    "exp": { "cols": 4, "rows": 2, "frames": 8, "cellW": 192, "cellH": 192 },
    "layers": [
      { "id": "lr_my_burst_1", "type": "emitter", "name": "Sparks",
        "em": { "bursts": [{ "t": 0, "n": 40 }], "speed": 600 },
        "pt": { "life": 0.5, "sprite": { "kind": "shape", "id": "streak", "p": {} },
                "alignVel": true, "stretch": 1.6, "gravY": 380 } }
    ]
  },
  "tex": {} }
```

Полная схема — `docs/FORMAT.md`. Дефолты гидрации = фабрики `model.js`:

| Эмиттер (умолчания) | Спрайт-слой (умолчания) |
|---|---|
| blend add, start 0, end = dur | blend add, start 0, end = dur |
| em: point (0,0), dir out, angle −90, spread 40, speed 300 ±50%, rate 0, **bursts [{t:0,n:24}]**, seed 1 | sp: soft 220px, aspect 1, color белый |
| pt: life 0.8 ±30%, sprite smoke, size 90 ±40%, sizeOL grow, opacityOL fadeOut, grad fire, spin 40, drag 2 | opacity 1, scale 1 — статика, без ключей |

ЛОВУШКА дефолтов: эмиттер без `em.bursts` получает burst 24 частицы — для потока
задавать `"rate": N, "bursts": []`. Спрайт-слой и atlas анимации по умолчанию НЕ
несут: вспышке появление/затухание задаются ключами `opacity`/`sp.scale` явно.

Потолки симуляции: **5000 живых частиц** на слой-эмиттер (жёсткий срез в `sim.js`),
`em.sub.budget` — отдельный кап на детей. Шаг симуляции фиксирован 1/120 с.

## Координаты, время, единицы

- (0,0) — ЦЕНТР композиции, **Y вниз**: `gravY: 380` — падение, `gravY: -60` — дым вверх.
- **Композиция — параметр дизайна, а не константа.** 512×512 — умолчание, но луч
  живёт в 512×32 (railgun), иконочный эффект — в 128×128 (Poison, апскейлится
  в ячейку атласа 256×256). Кадр выбирается под силуэт эффекта.
- Скорости px/с: ~100 лениво, ~300 средне, 600+ выстрел. Жизнь: 0.3–0.5 резко,
  0.8–1.2 плавно, 2+ атмосфера.
- `layers[0]` — ВЕРХНИЙ слой (рисуется последним). Порядок в рецептах ниже — сверху вниз.
- Время ключей треков — от НАЧАЛА СЛОЯ (перенос слоя двигает анимацию с ним).
- `start` может быть < 0 — пре-ролл: к t=0 частицы уже в полёте (эталонный
  Explosion стартует слои с −0.085, чтобы первый кадр атласа не был «зачаточным»).
- Эмиттер: `start..end` — окно ЭМИССИИ, частицы доживают после end.
  Спрайт/футаж: `start..end` — окно видимости. Постэффект: окно работы.
- `cam.comp` (градусы): 0 — вид сбоку, 32–37 — изометрия ARCADIA (scaleY ≈ 0.84…0.8).
  Плющит только render-позиции; `squash` 0..1 — плющить ли сам спрайт (кольца
  ударной волны на изометрии — squash 1).

## Треки, кривые, градиенты

- Трек: число ИЛИ `{"keys":[{"t":0,"v":1,"i":{"m":"ease"},"o":{"m":"ease"}}]}`;
  режимы `lin|ease|hold(только o)|cust` (`h:[x,y]`, y без клампа — овершут легален).
- **Трек держит края**: до первого ключа — значение первого, после последнего —
  значение последнего. Пустой `{"keys":[]}` = 0 (валидатор предупреждает).
- Анимируемы ТОЛЬКО: слой `opacity glowL fadeX fadeY fadeR`; em `x y sx sy angle
  spread speed rate`; узлы пути `path.nodes[].x/y` + `jitter attract lock flow`;
  pt `size gravX gravY turbAmp`; суб-эмиттер `sub.rate sub.speed`;
  sp `x y scale rot glow color`;
  postfx `length angle spin x y` (mblur) и `amount y0` (displace);
  силовое поле `ff.fields[].strength x y sx sy` (`falloff` — статика).
  Остальное — статика (валидатор ловит трек не по месту).
- **Анимация эмиттера — самый недоиспользованный инструмент.** В library её почти
  нет, а даёт она то, чего частицами не сделать:
  - `em.x/y` треком — источник едет (падающая комета, летящий снаряд с хвостом);
  - `em.angle` треком — развёртка веера, «поворот струи», конус, который водит;
  - `em.spread` от 0 к 180 — выстрел, раскрывающийся в облако;
  - `em.speed` треком — резкий выброс с затуханием без изменения rate;
  - `em.sx/sy` треком — растущее кольцо/бокс рождения (волна, идущая наружу);
  - `em.rate` меандром — пыхи вместо ровной струи (Flame Pro; 4 Гц).
- Кривые за жизнь (t: 0..1 жизни частицы): `sizeOL`/`opacityOL` = `{"pts":[{"t":0,"v":1},…]}`,
  Catmull-Rom, v ≥ 0. Итог: размер = size·sizeOL(lf), альфа = opacity·opacityOL(lf).
- `sizeOT` — ТОЛЬКО для трейлов: множитель ширины ВДОЛЬ ПУТИ (0 — хвост/место
  спавна, 1 — голова). Poison: `0 → 0 → 0.48 → 1.6` — капля-запятая с острым хвостом.
  Константа 1 = однородный штрих.
- Градиент `grad` = `{"stops":[{"t":0,"c":[r,g,b]},…]}` — ЦВЕТ за жизнь, БЕЗ альфы
  (альфа живёт только в opacityOL). Обычная драматургия огня: белый → жёлтый →
  оранжевый → тёмно-красный/бурый.
- Пресеты кривых (описания): const1 (ровно 1), fadeOut (1→0 с плато), fadeIn,
  inOut (вспышка-пульс), bell (0→1→0), grow (0.25→1), growFast (быстрый рост с
  овершутом 1.15), shrink (1→0.1), popShrink (хлопок 0.4→1→0.35).
- Пресеты градиентов: fire, fireHot (плазма), smoke, smokeLight, spark, ice,
  energy (бирюза ARCADIA), poison, white, gold. В JSON пресеты не сослать —
  копировать стопы (источник: `js/core/curve.js`).

## Спрайты частиц (`sprite: {kind:'shape', id, p}`)

Все процедурные — белые 128px, тонируются градиентом автоматически.

| id | Что это | Куда |
|---|---|---|
| soft | мягкий радиальный круг | вспышки, глоу, дым-подложка |
| dot | круг с жёсткой кромкой | снег, пузыри, точки, брызги суб-эмиттера |
| ring | кольцо (p.th 0.02–0.9) | ударные волны |
| square | квадрат | пиксельная крошка, техно |
| poly (p.n 3–16) | правильный многоугольник | магия, кристаллы, пикапы |
| star (p.n 3–12, p.inr) | звезда | глинты, награды, мана |
| streak | горизонтальный штрих | искры с alignVel+stretch |
| spark | крест-блик | звёздочки, глинты, блики на металле |
| flame | язык пламени, остриё в +X, 4 варианта (p.taper) | язык с alignVel |
| ember | уголёк: белое ядро + тёплый ореол | искры на add |
| smoke | клубы дыма, 4 варианта | дым, взрывы, МАССА огня |
| blob | мультяшный клуб, 4 варианта | cartoon-взрывы, пламя |
| shard | осколок, 4 варианта | обломки, дебрис, ледяная крошка |

`square/poly/star/spark` в library не использованы ни разу — для всего
неорганического (техно, магия, лут, лёд) начинать надо с них, а не с `soft`.
Вариативные (smoke/blob/shard/flame): случайный вариант на частицу; `p.var: 0..3` —
зафиксировать один.

## Слои: четыре типа

- **`emitter`** — частицы (`em` + `pt`). Основной инструмент.
- **`sprite`** — одна картинка (`sp`): вспышка, кольцо, подложка, готовый рендер.
  Дефолт статичен (opacity 1, scale 1): анимацию вспышки задавать ключами.
- **`atlas`** — футаж: источник ВСЕГДА текстура-лист (`sprite:{kind:'tex'}` у
  текстуры со `sheet`). Схема — тот же `sp`, но дефолт `blend: normal`.
  `sp.color`/`sp.glow` не действуют (текстуры не тонируются).
- **`postfx`** — слой-корректор: своего изображения нет, гнёт/мажет ПИКСЕЛИ всего,
  что НИЖЕ по стеку. `opacity` = сила эффекта; `glowL`/`fadeOn` мертвы, `blend`
  читается только в адресованном режиме (блендинг группы).
- **`force`** — слой-корректор ФИЗИКИ: ни картинки, ни пикселей. Радиальные поля
  (`ff.fields[]`: `collapse` к центру / `expand` от центра / `drive` по касательной)
  добавляют ускорение частицам эмиттеров ниже. `opacity` = общий множитель силы.
- У обоих корректоров `targets` пуст = «всё, что ниже» (дефолт); непустой сужает
  до перечисленных слоёв. У `force` адресатами могут быть только эмиттеры.

## Силовые поля (`type: 'force'`)

Единственный способ ИЗОГНУТЬ траектории готовым слоем, а не переписывать физику
каждого эмиттера. Поле живёт в мировых координатах, поэтому один слой одинаково
тянет искры, дым и трейлы — и его удобно анимировать как самостоятельный «актёр».

- `collapse` — воронка/всасывание: частицы сходятся к центру. Сильный `falloff`
  (3+) даёт узкое горло, при котором края облака почти не двигаются.
- `expand` — отброс/ударная волна изнутри. Ставится ключами: 0 -> пик -> 0.
- `drive` — вихрь: скорость набирается по касательной, и частицы уходят по спирали
  наружу (центробежная составляющая — не баг, а физика). Для тугого смерча
  комбинируйте `drive` с `collapse` в одном слое.
- Область — ЭЛЛИПС `sx/sy`, за ним сила ровно ноль: поле можно ставить вплотную
  к тому, что трогать нельзя. `sy >> sx` даёт «стену», вдоль которой сдувает.
- Сила — ускорение (px/с²), поэтому её масштаб такой же, как у `pt.gravY`, и
  `pt.drag` гасит её ровно так же. Сравнивать с `turbAmp` — по тем же числам.
- Проверка глазами: кнопка **Forces** в превью показывает суммарное поле стрелками
  (выбран эмиттер — всё, что на него действует; выбран слой поля — только его поля).

## Интуиция ключевых параметров

- **blend**: `add` — огонь/энергия/вспышки/электричество; `screen` — то же, но не
  выжигает в белое (мягкий верхний предел: пламя, ауры, толстые трейлы);
  `normal` — дым, обломки, мультяшные клубы, футаж. Тёмное на add невидимо —
  тёмные хвосты градиента требуют normal.
- **rate vs bursts**: взрыв/импульс — `bursts`; поток/луп — `rate` + `bursts: []`.
  Несколько записей в `bursts` — ритм: `[{t:0,n:60},{t:0.12,n:24},{t:0.3,n:10}]`
  даёт удар с эхом вместо одиночного хлопка.
- **alignVel + stretch**: частица ложится по скорости и растягивается от неё
  (искры: streak + stretch 1.6). **spin/spinRnd** — вращение клубов;
  **rot/rotRnd** — стартовый угол (rotRnd 1 = полный разброс).
- **drag**: 0 — баллистика; 1–2 — мягкое торможение; 3–4 — резкий выброс и стоп
  (взрывное «расталкивание»); 7+ — частица тормозит почти мгновенно (railgun).
- **turbAmp/turbFreq** — плавная органика (снег 160/0.8).
  **zigzag** (град/с) — покадровые ИЗЛОМЫ (молния 900–2000), не путать с турбулентностью.
- **turbMode 'curl'** — вихревое ПОЛЕ в мировых координатах вместо дрожания на
  частицу: соседние частицы едут вместе связной струёй. Всё, что течёт (огонь, дым,
  пар, аура), хочет именно его. Ключевые: `turbScale` (размер вихря, px),
  `turbWind` (поле как скорость среды — несёт частицу, нужно `drag > 0`),
  `turbRise` (поле всплывает, ~0.6 скорости подъёма), `turbRamp` (ламинарный низ).
- **Языки/рвань — это НЕ спрайты и НЕ турбулентность.** Форму режет постэффект
  `displace` (см. ниже). Возить по полю фигурные спрайты бесполезно: alignVel ставит
  их все по одной скорости, и выходит грядка одинаковых капель.
- **render 'trail'**: линия пути частицы (ширина = size·sizeOL·sizeOT), `trailCore` —
  белое ядро. Для свечения трейлов использовать ПОСЛОЙНОЕ `glowL` (0..3) +
  `glowLR` (px), а не только per-particle `glow`.
- **glow** (частицы, 0..3): 0.3–0.5 лёгкий ореол, >1 — мультипроходы (дорого).
  `glowSize` — размер ореола, `glowBlur` — мягкость.
- **fadeOn + fadeX/Y/R/Soft** — радиальное затухание слоя (обрезать молнию у земли,
  локализовать свечение, спрятать точку рождения луча).
- **em.seed** — другая случайность того же дизайна. Несколько похожих слоёв —
  разные seed, иначе паттерны синхронны.
- **lifeRnd/sizeRnd/speedRnd** 0.3–0.6 — живость; 0 — механическая регулярность.

## Суб-эмиттеры (`em.sub`)

Каждая частица слоя сама работает эмиттером — дочерние частицы описываются
ПОЛНЫМ блоком `em.sub.pt` (та же схема, что `pt`: свой спрайт, градиент, кривые,
трейл, турбулентность). Выключено по умолчанию (`on: false`).

Это единственный способ получить **вторичное событие, привязанное к частице**:
шлейф за каждой искрой, брызги в точке гибели, распад снаряда на осколки,
капли, стекающие с ядовитого облака.

- `emit`: `death` — выброс при гибели родителя (`count` штук); `life` — сыпать по
  ходу жизни (`rate` частиц/с НА КАЖДОГО родителя, `startAt` — с какой доли жизни
  начать); `both` — и то, и другое.
  **`life`/`both` в library не использованы ни разу** — а это дымный шлейф за
  снарядом, искры вдоль трассы, пыль за колесом.
- `dir`: `omni` (во все стороны) | `inherit` (вдоль скорости родителя ±`spread`) |
  `back` (назад — шлейф) | `out` (от центра эмиттера). Параметр `inherit` (0..1)
  добавляет ребёнку долю скорости родителя — без него дети «отстают» от быстрых.
- `maxGen` 2..4 — дети детей ТЕМ ЖЕ блоком `sub.pt`, `genScale` (≈0.6) ужимает
  size/life/rate каждому следующему поколению. Каскад, фрактальный распад.
  **В library не использовано.**
- `budget` — кап живых детей (1500 по умолчанию). `under: true` — рисовать детей
  ПОД родителями (Poison: капли уходят за облако).
- Ветки `em.branch` — другое: они наследуют `pt` РОДИТЕЛЯ и его направление
  (молния разветвляется сама в себя). Суб-эмиттер порождает ДРУГОЙ вид частиц.

Эталоны: `flame.json` (искры-`dot` отлетают от гибнущих клубов пламени,
`dir: inherit`, `count: 2`), `Poison.json` (`under: true`, `blob`-капли в точке
гибели трейла).

## Путь движения (`em.path`)

Анимируемая ломаная/кривая, вдоль которой эмиттер рождает и/или ведёт частицы.
Узлы — смещения от `em.x/em.y`, **у каждого узла свои треки x/y**. Выключен
по умолчанию (`on: false`).

- `mode`: `emit` — частицы рождаются вдоль пути; `guide` — рождаются как обычно,
  но ведутся к пути; `both`.
- `along` (для emit): `random` | `even` (низкая дискрепанция — ровная нить без
  комков) | `start` (все в начале пути — трасса, которая ВЫСТРЕЛИВАЕТ вдоль).
- `aim`: `none` (работает `em.dir`) | `tangent` (вдоль пути) | `normal` (поперёк).
  Aim ПЕРЕКРЫВАЕТ `em.dir`.
- Ведение: `attract` (пружина к ближайшей точке, 1/с²), `lock` 0..1 (жёсткое
  прилипание; 1 — движение строго по кривой), `flow` (скорость вдоль касательной,
  минус — назад), `jitter` (разброс поперёк пути, px).
- `closed` — замкнуть, `smooth` — Catmull-Rom через узлы (от 3 узлов) vs ломаная.

Три разных приёма из одного механизма:

1. **Луч/трасса** — `mode: both`, `along: start`, `aim: tangent`, `lock: 1`:
   частицы стартуют в начале и едут строго по кривой. Кривая с лёгкой змейкой в
   узлах = плетёный луч (railgun: 4 слоя с разными змейками и разной скоростью).
2. **След клинка** — узлы АНИМИРОВАНЫ треками: точка пути описывает дугу удара,
   `mode: emit`, `along: even`, высокий `rate`, `render: trail`. Частицы
   выкладываются по мгновенному положению кривой — получается заметаемый след
   (saber: `rate 10000`, `speed 0`, `closed: true`, `smooth: false`).
3. **Ведение потока** — `mode: guide` + `attract` 2–3: частицы летят своим ходом,
   но их подсасывает к линии. Сужает столб пламени кверху, собирает дым в струю,
   заворачивает ауру по орбите. **В library не использовано.**

## Постэффекты (`type: 'postfx'`)

Слой-корректор обрабатывает ПИКСЕЛИ всего, что ниже него по стеку. Дискриминатор
вида — `fx.effect`. Байпас (`opacity 0`, нулевая сила, время вне окна слоя)
ничего не стоит — оффскрин-композиция не создаётся вовсе.

Непустой `targets` переводит корректор в АДРЕСНЫЙ режим: перечисленные слои
рисуются в изолированную группу, эффект идёт по ней, и группа кладётся обратно
на месте корректора с его `blend` (аддитивным слоям — `add`, иначе группа ляжет
обычным normal и перестанет складываться с фоном). Так одним смазом мажут искры,
не трогая дым под ними.

### `effect: 'mblur'` — смаз

Даёт ощущение СКОРОСТИ, которого частицами не добиться: размазанная по кадру
трасса, вращающийся вихрь, «длинная выдержка».

- `mode: 'directional'` — смаз по углу: `length` (px), `angle` (град). Луч,
  рывок, удар (railgun: length ≈ 5 вдоль трассы — трасса «плывёт», а не мигает).
- `mode: 'radial'` — от центра `x/y`: `length` — зум-смаз (на дальнем углу кадра),
  `spin` — угловой смаз в градусах. Вращение, взрывной зум, шлейф вокруг точки
  (saber: центр вынесен в точку рукояти, `spin` подкручивает дугу).
- `samples` 2|4|8|16|32|64 — набираются log2(N) проходами; 16 хватает почти всегда.
  `half: true` — считать в половинном буфере (быстрее и мягче).
- `length`/`angle`/`spin` — треки: смаз можно ВКЛЮЧАТЬ на кадр удара и гасить.
  В library анимации постэффектов нет ни одной — свободный приём.

### `effect: 'displace'` — турбулентное искажение

Главный инструмент формы для всего текучего: огонь, дым, пар, порталы, щиты.
Частицы дают мягкую светящуюся массу, а форму — складки, рвань, отрывающиеся
лоскуты — режет искажение.

- Ставить НАД слоями массы, но ПОД искрами и мелкой чёткой деталью
  (размазанная искра перестаёт быть искрой).
- `field 'swirl'` — площадь сохраняется, дыр в массе не выбивает (дефолт);
  `'tear'` рвёт резче, но дыры на пламени читаются как прогары.
- `aspect` 2–3 — складки вытянуты вверх (языки, а не кляксы).
- `rise` — поле уплывает вверх; **отрицательный тоже легален** (Flame Pro: −71,
  поле сползает вниз, языки читаются как поднимающиеся навстречу).
- `ramp`/`y0`/`soft` — успокоить основание; всему, что стоит на земле, иначе
  вихрь растаскивает низ вбок и под объектом появляется яркая полоса-лужа.
- **Две рабочие точки по масштабу складки** — обе легальны, выбирать по картинке:
  - *крупная складка*: `scale` ≈ четверть ширины объекта, `amount` ≈ 2·`scale`
    (swirl) или ≈ 1·`scale` (tear) — гнёт силуэт целиком, столб ходит змейкой;
  - *мелкая складка*: `scale` ≈ 1/6…1/8 ширины, `amount` ≈ 0.3…0.5·`scale`
    (эталон Flame Pro после ручной доводки: `scale 17`, `amount 6`, `evo 0.055`,
    `oct 2`, `ramp 0`) — силуэт стоит на месте, рвань идёт по краям.
  Складка ШИРЕ объекта возит его целиком вбок — это покачивание, не языки.

## Текстуры и футаж

Редактор — не только партикл-система: он собирает композицию и из готовых
картинок и секвенций. Это отдельный, полностью рабочий маршрут (Capacitor —
эффект целиком из трёх текстурных слоёв, без единой частицы).

- Мета текстуры — в `doc.textures` (`{id, name, sheet}`), пейлоад dataURL —
  в `file.tex[id]`. Без пейлоада валидатор предупреждает: файл не самодостаточен.
- `sheet: {cols, rows, fps}` помечает текстуру как ЛИСТ-футаж.
- Частица с текстурой: `pt.sprite = {kind:'tex', texId}`; `tintTex: true` —
  тонировать градиентом (Explosion). `pt.fps > 0` — крутить лист по возрасту
  циклом; `pt.fps = 0` — растянуть лист ровно на жизнь частицы.
- Слой `atlas`: `sp.fps > 0` — крутить циклом по времени слоя; `sp.fps = 0` —
  растянуть лист на окно `start..end`. **Анимации футажа (`fps > 0`) в library
  нет ни одной** — все листы растянуты на окно.
- Выгрузить исходники: `node tools/collect.mjs` → `library/textures/`.

## Рецепты архетипов (слои сверху вниз; читать эталон перед сборкой)

- **Взрыв** — эталон `library/Explosion.json` (7 слоёв, доведён руками):
  Flash (soft, scale up + fade за ~0.2с) / Sparks (burst 40–110, streak,
  alignVel+stretch, gravY 130+) / Shockwave (ring, squash 1, scale 0.5→2.4,
  opacity 0→0.7→0) / Flame (blob, blend normal, circle+omni, spin) /
  опц. электро-дуга (trail+branch+zigzag, glowL, fadeOn) / Smoke (blend normal,
  gravY −60, пик opacityOL ~0.2). Пре-ролл −0.08, атлас обрезан `exp.t1≈0.55`.
- **Пламя (луп)** — эталон `library/Flame Pro.json` (6 слоёв, сверху вниз:
  Sparks / Bloom / **Turbulence (postfx displace)** / Detached licks / Tongues /
  smoke). Схема, а не набор чисел: ЧАСТИЦЫ ДАЮТ МАССУ, ИСКАЖЕНИЕ ДАЁТ ФОРМУ.
  Снизу вверх — smoke (normal, ПОД огнём: аддитивному пламени нужно тёмное за
  спиной) / Tongues (основная масса, box-эмиттер, спрайт `flame`) / Detached licks
  (короткоживущие оторвавшиеся языки) / **postfx displace** / Bloom (screen,
  мягкое свечение) / Sparks (НАД искажением: размазанная искра не искра).
  Огненные слои: `turbMode 'curl'` + `turbWind`/`turbRise`/`turbRamp` 0.8–0.9,
  `dir: 'dir'` вверх, `subStep: false`.
  Пыхи: `em.rate` треком, меандр 4 Гц — плюм срывается кольцами, а не течёт струёй.
  Альфа частицы на add — 0.03–0.1, яркость набирается ПЕРЕКРЫТИЕМ; иначе основание
  слипается в белую плиту. Пик opacityOL сдвинут вглубь жизни (~0.3), иначе все
  частицы вспыхивают на линии рождения.
  ЛУП: `comp.dur 4` с запасом (дым выходит на режим только к своей жизни ~2.4 с),
  атлас-окно `t0/t1` = ЦЕЛОЕ число периодов пыха в стационаре.
  Более простой вариант того же архетипа — `library/flame.json`: два эмиттера на
  `rate`, `screen`, суб-эмиттер искр, окно лупа `exp.t0 1.5 / t1 2.5`.
- **Луч / трасса / рельса** — эталон `library/railgun.json`. **Композиция 512×32**
  (кадр по силуэту, не квадрат). Сверху вниз: postfx mblur directional (length ~5)
  / два слоя-«змейки» (`path` с 6 узлами лёгкого зигзага, разные speed/drag/glowL —
  плетение) / два слоя ядра (`path` из 2 узлов — прямая, burst 128, glowL, fadeOn
  у краёв). Все: `path.mode 'both'`, `along 'start'`, `aim 'tangent'`, `lock 1`,
  спрайт `streak` + `alignVel`, `subStep: false`.
- **След клинка / замах** — эталон `library/saber.json`: Sprite (soft-блик у
  рукояти, треки x/scale) / postfx mblur **radial** (центр в рукояти, `spin`) /
  Emitter: point, `speed 0`, `rate 10000`, `render 'trail'`, `blend screen`,
  `glowL 2.5`, `path.mode 'emit'`, `along 'even'`, `closed: true`, `smooth: false`,
  и **узел пути анимирован ключами** — он и рисует дугу удара.
- **Молния** — эталон: заводской пресет `Lightning Strike` в `js/core/fxpresets.js`
  (id `fx_lightning`), а НЕ файл в library. Sky flash (soft, мерцание ключами
  opacity) / Impact flash + Impact sparks (start = момент прихода в землю) /
  Bolt: point-эмиттер сверху, dir вниз, speed ~1100, 2 частицы, trail +
  trailCore 0.85, zigzag 900+, branch chance 7–18 maxGen 3, glowL 1.4–1.9,
  fadeOn у земли, opacityOL с мерцанием и обрывом.
- **Ударная волна / энерго-кольцо** — эталон `library/Shockwave.json` (+ заводской
  Energy Ring): Flash / ringBurst-эмиттер (ring-форма, dir out, squash 1) /
  Sparks / ring-спрайт(ы) со scale-раздуванием. Изометрия: `cam.comp 37`, squash 1.
- **Искры** — эталон `library/Sparks.json`: Flash + один burst-эмиттер
  (см. параметры в Формате выше).
- **Облако / AoE на земле** — эталон `library/Poison.json`: **комп 128×128**,
  `cam.comp 32`, ячейка атласа 256×256 (мелкий комп апскейлится). Trail-частицы
  `shard` с `sizeOT` (острый хвост → толстая голова) + суб-эмиттер `death`
  с `under: true` (капли оседают ПОД облаком) + текстурный спрайт + ring.
- **Композит из футажа** — эталон `library/Capacitor.json`: ни одной частицы,
  три текстурных слоя (лист 3×3 как `type:'atlas'` + два `sprite` на add с
  анимированным scale), `exp.t1` обрезает хвост, ячейка 256×204 (неквадратная).
- **Дым столбом / маска** — заводской `Smoke — Mask` (fxpresets): smoke-спрайты,
  blend normal, gravY −70, opacityOL с длинным хвостом; экспорт `mode: mask`.
- **Снег / пепел / дождь** — layerPreset `snow`: box-эмиттер шириной композиции
  над кадром, rate, dir вниз, turbAmp; дождь — streak + alignVel + speed 700+.
- **Аура / пикап / стягивание** — `em.shape 'ring'` + `dir 'in'` (частицы летят
  К центру) либо poly/star с gravY −200 и fadeIn; grad energy/gold.
  `dir: 'in'` в library не использован — для «поглощения», «зарядки», «призыва»
  это первый кандидат.

## Атлас (exp)

- Кадры сэмплируются по ЦЕНТРАМ интервалов `t0..t1` (первый кадр burst-эффекта
  не пустой). `t1: -1` = до конца композиции. `frames ≤ cols·rows` (иначе кламп).
- Ячейка — уменьшенная копия ВСЕЙ композиции (fit): крупный эффект в кадре =
  правильный `comp.w/h` или кроп через t0/t1, а не cellW/H. Ячейка не обязана быть
  квадратной (Capacitor 256×204, flame 128×192) — она повторяет пропорции комп.
- `ss` 1|2 — суперсэмпл при сборке (2 по умолчанию).
- mode: `rgba` (обычный), `black` (на чёрном), `mask` (белая маска + `thr`).
- Мета для Phaser — кнопка Meta JSON (frameWidth/Height, fps).
